# Client–Server Prototype

This prototype demonstrates a basic client–server architecture using
Node.js and Express.

## Purpose
Validate HTTP-based request–response communication between a client
and a backend server.

## Endpoint
GET /ping  
Returns a JSON response to confirm connectivity.

## Clients
- Web browser
- curl
- Postman

## System Design Relevance
This prototype supports the documented client–server architecture by
providing a minimal working backend implementation.
